One one-line comedy joke: therapy advice taken literally — a velvet rope
around the speaker's feelings, with a cover charge. One image, two turns,
deadpan delivery, and it still lands on a second read.

The program (`main.ts`) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
It is fixed and deterministic — the same bytes on every run, no clock, no
randomness, no network — and stays well inside the gate's 1–280 character band.

## Run it

```sh
node main.ts
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset).

## The line

> My therapist told me to set boundaries, so I put a velvet rope around my feelings and started charging admission.
